# 🔐 CryptoShit

> Учебный проект для изучения основ современной криптографии, шифрования данных и работы с Web Crypto API.

**CryptoShit** — небольшой экспериментальный проект, посвящённый практическому знакомству с симметричным шифрованием.

Проект позволяет шифровать и расшифровывать текстовые сообщения и файлы прямо в браузере, используя **AES-256-GCM**. В качестве источника ключа можно использовать как готовый 32-байтный ключ, так и пароль, из которого ключ получается с помощью **PBKDF2**.

> ⚠️ **Важно:** проект создан в учебных целях. Не используйте его для защиты реальных секретов, паролей, приватных ключей или другой критически важной информации без дополнительного аудита и тестирования.

- 📋 Копирование результата в буфер обмена
- 💾 Сохранение результата в файл
- 🌐 Работа непосредственно в браузере

## 🧠 Что изучается в проекте

Основная цель CryptoShit — не создать очередной production-ready менеджер секретов, а разобраться, **как на практике устроено симметричное шифрование**.

В процессе работы с проектом можно изучить:

- AES;
- режим GCM;
- 256-битные ключи;
- Initialization Vector (IV);
- salt;
- PBKDF2;
- Base64;
- `ArrayBuffer` / `Uint8Array`;
- Web Crypto API;
- работу с файлами в браузере;
- сериализацию криптографических данных в JSON.

## 🔐 Как это работает

### Вариант 1 — готовый ключ

Пользователь может указать собственный ключ размером **32 байта (256 бит)** в формате Base64.

```text
Base64 key
     │
     ▼
  32 bytes
     │
     ▼
AES-256-GCM
     │
     ├── IV
     └── Plaintext
          │
          ▼
      Ciphertext
```
##Вариант 2 — пароль##

Если вместо ключа используется пароль, проект сначала получает из него криптографический ключ с помощью PBKDF2 и случайной соли.
```text
Password
    │
    ▼
  PBKDF2
    │
    ├── Salt
    │
    ▼
256-bit key
    │
    ▼
AES-256-GCM
```
Соль сохраняется вместе с результатом шифрования, поэтому при расшифровке её можно использовать повторно.
Формат результата

**Зашифрованные данные сериализуются в JSON.**

Упрощённо результат выглядит следующим образом:
```text
{
  "alg": "AES-256-GCM",
  "mode": "password",
  "salt": "...",
  "iv": "...",
  "data": "..."
}
```
##Запуск##

Проект не требует отдельного backend-сервера для браузерного прототипа.

**Вариант 1 — открыть страницу напрямую**

Откройте:
```text
index.html
```
в современном браузере.
**Вариант 2 — локальный HTTP-сервер**
Для более корректной работы браузерных API можно запустить простой локальный сервер.

Например, через Python:
```
python -m http.server 8000
```
После этого откройте:
```
http://localhost:8000
```
